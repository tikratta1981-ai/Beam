  วิธีแก้ปัญหา npm run dev / tsx not recognized
========================================

[ปัญหา 1] 'tsx' is not recognized
สาเหตุ: ยังไม่ได้ติดตั้ง tsx หรือ npm install ไม่ครบ
วิธีแก้:
  cd /d "D:\New folder (65)"
  npm install --legacy-peer-deps
  npm install -D tsx --legacy-peer-deps
  npm run dev

ถ้ายังไม่ได้:
  npx tsx server.ts


[ปัญหา 2] npm error code ERESOLVE
สาเหตุ: dependency conflict ระหว่าง esbuild, vite, @tailwindcss/vite
วิธีแก้เร็ว:
  npm install --legacy-peer-deps

ถ้ายังไม่ได้:
  เพิ่มใน package.json:
  "overrides": {
    "@tailwindcss/vite": {
      "vite": "^8"
    }
  }
  แล้วรัน:
  npm install --legacy-peer-deps

หรืออัปเดต:
  npm install @tailwindcss/vite@latest
