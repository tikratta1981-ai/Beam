1. ภาพรวมเทคโนโลยีและสถาปัตยกรรม (TECH STACK & ARCHITECTURE)
--------------------------------------------------------------------------------
- Framework: React 18 (SPA) + TypeScript
- Build Tool: Vite
- Styling: Tailwind CSS
- 3D & Graphics: Three.js (@react-three/fiber, @react-three/drei) + Custom Isometric SVG 3D Layer
- Audio: Web Audio API (Synthesizer & Chimes) + Custom Audio Management
- Security & Anti-Cheat: In-memory & LocalStorage integrity checks, Crypto, RateLimiter, TimeGuard
- State Management: React useState / useEffect / useCallback / useRef Hooks (Single Source of Truth in App.tsx)

3. วงจรการทำงานหลักของเกม (CORE GAME LOOP IN App.tsx)
--------------------------------------------------------------------------------
1. Player Stats State:
   - coins (เหรียญ), diamonds (เพชร), level (เลเวล), exp (ค่าประสบการณ์)
   - energy (พลังงาน), maxEnergy (ขีดจำกัดพลังงาน)

2. Farm & World State:
   - plots: อาร์เรย์ของแปลงเพาะปลูก (id, cropId, plantTime, harvestTime, state, isWatered, x, y)
   - animals: รายการสัตว์เลี้ยง (id, type, fedTime, readyTime, state)
   - inventory: ยุ้งฉางเก็บพืชผลและวัตถุดิบ (สาลี, ข้าวโพด, มะเขือเทศ, นม, ไข่ ฯลฯ)
   - orders: ออเดอร์ของรถส่งของ (รายการสินค้าที่ต้องส่ง + ผลตอบแทนเหรียญและ EXP)
   - quests: ภารกิจประจำวันและเป้าหมายความสำเร็จ
   - activeFarm: สลับมุมมองระหว่าง 'farm' (ฟาร์มหลัก) และ 'lake' (ท่าตกปลา)
   - isEditMode: โหมดจัดฟาร์ม (ย้ายแปลง ลบแปลง เพิ่มแปลง)

3. Harvesting & Sowing Lifecycle:
   - ปลูก (Planting): เลือกแปลง -> เปิด SeedPickerModal -> หักเมล็ด -> บันทึก plantTime & harvestTime
   - เติบโต (Growing): ตรวจสอบเวลาผ่าน TimeGuard และ GameConstants
   - รดน้ำ (Watering): เร่งเวลาเติบโตร้อยละ 30
   - เก็บเกี่ยว (Harvesting): ลากเคียวหรือคลิกแปลง -> รับผลผลิต 10 ชิ้นต่อแปลง -> คำนวณคอมโบ -> มอบ EXP & เหรียญ -> เล่นเสียง Chime

   - ปรับปรุงการคำนวณตำแหน่งเริ่มต้น (Fallback Coordinates) ใน FarmWorld.tsx ให้ใช้ดัชนีของอาร์เรย์ (plotIndex % 5) แทน plot.id ป้องกันแปลงที่เกิดจาก Timestamp กระโดดออกนอกหน้าจอ
